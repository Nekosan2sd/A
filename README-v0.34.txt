タマヨケ v0.34 Wi-Fiマルチプレイ 起動手順
================================================

【必要なもの】
・ホスト用PC 1台（Windows / macOS / Linux）
・Node.js 18以上
・全端末が接続できる同じWi-Fi

【初回だけ行う準備】
1. tamayoke-v0.34.zipを展開します。
2. 展開したフォルダーを開きます。
3. フォルダー内でターミナルを開きます。
4. 次のコマンドを実行します。

   npm install

【サーバーの起動】
1. 同じフォルダーで次を実行します。

   npm start

2. 画面に次のようなURLが表示されます。

   タマヨケ v0.34 LAN server: http://localhost:8080
   同じWi-Fiから: http://192.168.x.x:8080

3. ホストは http://localhost:8080 を開きます。
4. 参加者は「同じWi-Fiから」に表示されたURLをブラウザで開きます。
5. ゲーム内でホストが「ルームを作る」を押します。
6. 表示された6桁コードを参加者へ伝えます。
7. 参加者は同じ6桁コードを入力して参加します。
8. 全員が待機室に表示されたら、ホストが「ゲーム開始」を押します。

【2回目以降】
展開済みフォルダーで npm start を実行するだけです。

【終了方法】
サーバーを起動したターミナルで Ctrl+C を押します。

【接続できない場合】
・全端末が同じWi-Fiか確認してください。
・ゲストWi-Fiや学校・施設のWi-Fiでは端末間通信が禁止されている場合があります。
・Windowsファイアウォールが表示された場合は、プライベートネットワークでNode.jsを許可してください。
・VPN、モバイル通信、プライベートリレーを一時的に無効化して確認してください。
・URLの末尾に :8080 が含まれているか確認してください。
・server.jsを直接ダブルクリックせず、npm startで起動してください。

【ファイル構成】
・tamayoke-v0.34.html  HTMLとCSS、メニュー画面
・game.js              ゲーム本体、メニュー制御、WebSocket通信、相手表示
・server.js            LANサーバー、6桁ルーム、最大4人管理
・package.json         起動設定とwsライブラリ

【通信仕様】
・20Hzで位置、向き、HP、リロード状態を送信
・6桁コードはルーム識別子
・最大4人
・ホスト退出時は残った参加者へホスト権限を移行
・3秒以上更新がない相手は画面表示から除外
